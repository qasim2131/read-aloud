Read Aloud diagnostics

The last 20 runs, newest first. Each row is one stage of a single read, with how long it took and the exact error if it failed. Click a run to expand it.

What is recorded: timings, stage outcomes, error messages, character and byte counts, the chosen voice, and the page's origin (for example https://example.com). What is never recorded: the selected text, the translated text, any URL path or query, and your dictation transcript - only counts of them.
subprocessMs covers the whole Piper process: spawn, loading the voice model, and synthesis. Piper reports no separate model-load timing, and its only load-related output echoes the input text back, which is not something worth putting in a file you might share. Chrome starts a fresh Piper process for every chunk, so that cost is paid per chunk.
