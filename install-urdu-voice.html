Install the Urdu voice

Urdu translation reads aloud using a local, offline voice (Piper) instead of sending your text anywhere. It's a one-time install, about 65 MB, and only affects Urdu - every other language is unaffected.

⬇ Download Urdu Voice Installer

After it downloads

  1. Open it from your Downloads folder.
  2. macOS will say it's from an unidentified developer - right-click the file and choose Open, then click Open again in the dialog. (This is a one-time step for any app downloaded outside the App Store - it isn't specific to this installer.)
  3. Click Continue / Install in the installer, and enter your Mac password when asked - the same password you'd use to install any Mac app.
  4. Quit and reopen Chrome (Chrome only checks for this the first time it starts).
  5. Open the Read Aloud extension again - Urdu will work automatically, no further setup.

No typing, no Terminal - just double-clicking a downloaded file, like installing any other Mac app. Nothing about your browsing or your text is sent anywhere by this installer.
